The foundation of every AI conversation

Three steps, running automatically, every time.

1

Sanitize

Sensitive details — names, case numbers, financial figures, medical information — are identified and replaced with non-reversible placeholders before anything is transmitted.

2

Process

The AI provider receives only the placeholders. It never sees a real name, a real figure, or a real identifier — there is nothing sensitive to leak, retain, or train on.

3

Restore

When the response returns, AKILA restores the original values for display — your team sees a complete, normal answer, exactly as if nothing had changed.

The installer downloads, verifies (SHA-256), installs to ~/Applications, and removes quarantine flags automatically. View script

macOS: The app is ad-hoc signed and will trigger a Gatekeeper warning on first launch.
  1. Easiest: Use the one-line installer — it auto-removes quarantine flags.
  2. Manual: Download & open the DMG, drag AKILA Desktop Agent.app to your Applications folder.
  3. In Finder, right-click (Ctrl-click) the app → choose Open.
  4. Click Open in the dialog. This only needs to be done once.
Windows: Click More info → Run anyway in the SmartScreen dialog.
Linux: Make the file executable: chmod +x AKILA-Desktop-Agent-Linux.AppImage, then double-click to run. No root/sudo required.
