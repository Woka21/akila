The foundation of every AI conversation

Three steps, running automatically, every time.

1

Sanitize

Sensitive details — names, case numbers, financial figures, medical information — are identified and replaced with non-reversible placeholders before anything is transmitted.

2

Process

The AI provider receives only the placeholders. It never sees a real name, a real figure, or a real identifier — there is nothing sensitive to leak, retain, or train on.

3

Restore

When the response returns, AKILA restores the original values for display — your team sees a complete, normal answer, exactly as if nothing had changed.

Pilot build · v1.0.0

Get AKILA running in about ten minutes

Download the pilot pack, start the local server, load the extension. Everything runs on your own machine — nothing is sent anywhere.

Download AKILA-PilotPack-v1.0.0.zip

SHA-256 78c01c9e8d926965ad42b992b5ffa131ee8dde4bd61a0921eaa2b592a7741462 · checksum file

1

Unzip & start the server

Unzip the pack anywhere. Double-click AKILA-Server.command (macOS), server-start.bat (Windows) or run ./server-start.sh (Linux). First run installs dependencies + the ~600 MB language model — that's the five-minute part. Success looks like: Running on http://127.0.0.1:5001.

2

Load the extension

Open chrome://extensions in Chrome, toggle Developer mode on, click Load unpacked, and choose the extension folder inside the pack.

3

Send a protected message

On ChatGPT or Claude, type a sentence with a client name and phone number. It arrives tokenized; your real data comes back in the reply. Keep the server window open while working.
