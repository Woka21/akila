The foundation of every AI conversation

Three steps, running automatically, every time.

1

Sanitize

Sensitive details — names, case numbers, financial figures, medical information — are identified and replaced with non-reversible placeholders before anything is transmitted.

2

Process

The AI provider receives only the placeholders. It never sees a real name, a real figure, or a real identifier — there is nothing sensitive to leak, retain, or train on.

3

Restore

When the response returns, AKILA restores the original values for display — your team sees a complete, normal answer, exactly as if nothing had changed.

Desktop Agent · v1.0.0

One installer. Zero configuration. Automatic protection.

The AKILA Desktop Agent bundles the local sanitization server, manages the browser extension, and auto-starts on boot. Everything runs on your own machine.

🍎 macOS Apple Silicon & Intel (Universal binary) Download (.dmg, ~500MB)
🪟 Windows 64-bit (MSI installer) Download (.msi, ~500MB)
🐧 Linux AppImage — no installation needed Download (.AppImage, ~500MB)
macOS: If you see "AKILA Desktop Agent can't be opened because it is from an unidentified developer," right-click the .dmg file and choose Open, then click Open in the dialog. This only happens once for unsigned apps. For a permanent solution, use a machine with an Apple Developer ID to build the app, or contact us for an enterprise-signed build.
Windows: If Windows Defender shows a "Windows protected your PC" warning, click More info → Run anyway. The app is code-signed but may trigger SmartScreen for new releases.
Linux: Make the file executable: chmod +x AKILA-Desktop-Agent-Linux.AppImage, then double-click to run. No root/sudo required.

The desktop agent bundles the local Presidio server (with spaCy NLP models, ~500MB) and manages the browser extension. The app auto-starts the server on boot and opens the extension setup guide after installation.

Chrome Extension Setup

The AKILA Privilege Guard extension intercepts outbound messages on supported AI platforms and tokenizes PII before it's sent. Follow these steps to install it.

1

Download the Extension

Download the extension package. Version 1.0.0 with pinned extension ID kcnldfeclciolmbjfiomdfialhbccmhe. The ID is cryptographically pinned via the signing key, ensuring consistent behavior across installations.

Download Extension (.zip)
2

Extract the Extension

Unzip the downloaded file to a location you can easily find, like your Downloads folder. You should see files like manifest.json, background.js, and content-script.js.

3

Open Chrome Extensions

Navigate to chrome://extensions/ in your Chrome browser. This page allows you to manage all installed extensions.

4

Enable Developer Mode

Toggle Developer mode ON in the top-right corner of the Chrome Extensions page. This enables the "Load unpacked" button.

5

Load Unpacked Extension

Click Load unpacked, then navigate to and select the folder where you extracted the extension files in Step 2. Click Select Folder.

6

Verify Installation

You should see "AKILA Privilege Guard" listed on the extensions page. The extension icon will appear in your browser toolbar. Visit chatgpt.com and type a test message — you should see [AKILA] in the DevTools Console (Cmd+Opt+I).

Supported sites: ChatGPT, Claude, Google Gemini, GitHub Copilot, Perplexity AI, and any site with a text input (via universal sieve mode).

Desktop Agent (Recommended)

Download the platform-specific installer above (macOS/Windows/Linux), install the app, and let it auto-start the server. Then click "Install Extension" in the app UI to open the extension setup page.

B

Pilot Pack (Offline)

Download the AKILA-PilotPack ZIP, extract it, and run the platform-specific server script. Then load the extension from the extension/ folder inside the pack via chrome://extensions.

C

If you're developing, clone the repo, install Python dependencies in resources/server/venv, and run python3 presidio_server.py. Load the extension from src-tauri/resources/extension/ in unpacked mode.
