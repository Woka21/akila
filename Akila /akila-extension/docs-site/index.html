Install the Browser Extension

Step-by-step guide — no technical knowledge required.

Select your browser:

1

Download the Extension

Save the extension package to your Downloads folder.

Download Extension (.zip)

After downloading, right-click the file and choose Extract All (Windows) or double-click it (macOS) to unzip.

2

Open Your Browser's Extensions Page

Chrome / Brave: Type chrome://extensions/ in the address bar and press Enter.

Edge: Type edge://extensions/ in the address bar and press Enter.

Alternatively, click the three dots menu → More tools → Extensions.

3

Enable Developer Mode

On the Extensions page, toggle the Developer mode switch in the top-right corner to ON.

You should now see a blue Load unpacked button appear in the top-left corner.

4

Load the Unpacked Extension

Click the Load unpacked button.

In the file picker that opens, navigate to the folder where you extracted the extension. It should be named akila-extension (or similar).

Select that folder and click Select folder (or Choose).

Tip: The folder contains a file called manifest.json. Make sure you're selecting the folder, not the manifest file itself.

5

Pin the Extension to Your Toolbar

After loading, the extension appears in your Extensions list. You may see a puzzle icon 🧩 in your browser toolbar.

Click the puzzle icon, find AKILA Privilege Guard, and click the pin 📌 to keep it visible.

6

Verify It Works

Visit chatgpt.com and type a message containing a name or phone number.

You should see tokens like <AKILA_PERSON_7a3f> replacing the sensitive data.

If you don't see the AKILA icon in your toolbar, click the puzzle icon again to find it.

Troubleshooting

Extension not appearing?

Make sure you selected the folder (not a file) when clicking "Load unpacked". The folder must contain manifest.json.

Still seeing raw PII on chatgpt.com?

Ensure the Desktop Agent is running (look for http://localhost:8080). Restart your browser after installation.

Extension keeps getting disabled?

On Chrome, visit chrome://extensions, enable Developer mode, and click Details → enable Allow in incognito and Allow access to file URLs.

Security Architecture

AKILA is designed with defense-in-depth security principles.

🔒

Local-Only

All processing happens on your device. The server binds to 127.0.0.1 — it cannot be accessed from the network.

🛡️

Code-Protected

Python server compiled to bytecode zipapp. Extension JavaScript is obfuscated. Source files are not distributed.

⚡

Fail-Closed

If the server is unavailable, the extension blocks messages rather than risking PII leakage.

🔑

ID Pinning

Extension ID is pinned via signing key (kcnldfeclciolmbjfiomdfialhbccmhe) — consistent across all installations.
